# budget-ledger

A lightweight monthly budget tracker for managing income, expenses, and remaining balance by month.

## Features
- Add main income and extra income sources
- Track expenses by category and subcategory
- Paste notes from your phone or add items manually
- View totals and remaining balance by month
- Hebrew / English support

## Run locally
cd budget-ledger
python3 -m http.server 4200

Then open http://localhost:4200
